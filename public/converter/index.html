Avatar converter

Turns characters in other formats into a GLB file you can import as your player in Scale.

Download for Windows (ZIP, 6 KB)

Formats

FBX (e.g. Mixamo), Blender .blend, glTF/GLB, OBJ, DAE. GLB, glTF, VRM and FBX can also be imported in the game directly; the converter gives the most reliable result for FBX and is the only way for .blend.

How to use

  1. Unzip the folder anywhere.
  2. Drag your character file onto Convert.bat. You can drag animation files for the same rig along with it (Mixamo: character.fbx + Idle.fbx + Walking.fbx …); they become named animations.
  3. A .glb appears next to your file. In Scale's start screen, click Import model… or drag the .glb onto the start screen.

First run

The converter downloads the official portable Blender 4.5.12 (about 350 MB) from download.blender.org, checks its SHA-256 checksum and keeps it in a blender folder next to Convert.bat. Delete that folder to remove it. To use a Blender you already have, set the environment variable BLENDER_BIN to its blender.exe.

Good to know

  • Windows may warn about running a downloaded script. Convert.bat only starts convert.ps1 with PowerShell; both are plain text you can read.
  • Humanoid characters (Mixamo, VRM, Unreal-style, Rigify, most named rigs) get the game's full animation. Other rigs play their own animations if they have any.
  • Materials made from Blender's standard (Principled BSDF) setup and image textures convert; purely procedural shader materials do not.

macOS and Linux: not packaged yet. With Blender installed you can run blender -b --factory-startup -P convert_avatar.py -- out.glb model.fbx from the ZIP.
